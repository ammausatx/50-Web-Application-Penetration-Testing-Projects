# Screenshot Guide

Each of the 50 project READMEs embeds three project-specific SVG illustrations:

1. **Tool setup** — target scope, lab configuration, and baseline
2. **Test execution** — a simulated request, command, or test action
3. **Result review** — example observation, analyst validation, and retest context

All repository images are fictional training illustrations. They are not genuine tool captures, actual scan output, or proof of a vulnerability. Values and results are illustrative only.

When you perform a real assessment in an authorized lab:
- Capture the actual tool/browser view for each relevant step.
- Replace the illustrative image with your own redacted screenshot.
- Redact passwords, cookies, tokens, personal information, customer data, and unrelated hostnames.
- Preserve the original request, response, timestamp, tool version, and test account context in your private evidence record.
- Never present simulated output as real evidence or report an unverified finding.

Use intentionally vulnerable applications or systems covered by explicit written authorization only. Keep advanced tests isolated and use mock internal services, synthetic accounts, and disposable records.

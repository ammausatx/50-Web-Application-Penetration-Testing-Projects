# Screenshot Guide

Each project README embeds two relative image links from the repository's shared screenshot assets: a test execution illustration and a result review illustration.

These images are simulated training illustrations, not genuine scan output or proof of a vulnerability. When you run the lab:
1. Capture the actual tool or browser view for test execution.
2. Capture the result and analyst review.
3. Replace the illustrative image with your own redacted screenshot, or add project-specific screenshots and update the Markdown link.
4. Redact passwords, cookies, tokens, personal information, and unrelated hostnames.
5. Never present mock output as real evidence or report an unverified finding.

Use screenshots from owned or explicitly authorized labs only.
